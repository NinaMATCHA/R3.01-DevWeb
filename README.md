# R3.01-DevWeb
Projet R3.01

## Méthode pour tester son code en local et avancer le projet tranquillement sur ses branches

1- Créez un Workspace dans le dépôt

2- Créez votre branche

3- Faite votre code

4- Si vous voulez tester en local, lancez la commande : ```php -S 0.0.0.0:8000```

Une popup apparaîtra en bas à droite vous demandant si vous souhaitais ouvrir la fenêtre, acceptez alors.
